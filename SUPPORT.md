# Support

Use the VS Code Marketplace Q&A entry or GitHub Issues in the repository issue
tracker for support requests.

Before opening an issue, please include:

- Styio Language Support version
- VS Code version
- operating system
- whether `styio_lspd` is configured through `styio.server.path`,
  `STYIO_LSPD_PATH`, `STYIO_NIGHTLY_ROOT`, or `PATH`
- relevant lines from **Styio: Show Output**

Please do not paste private source files or secrets into public issues.
